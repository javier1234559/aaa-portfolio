# Design reference (Vite mock)

This folder contains a **static HTML/React prototype** (`aaa-portfolio/`) used for early layout and palette exploration.

**Production UI** lives in the Next.js app: `src/` with tokens in `src/app/globals.css` and typography in `src/app/layout.tsx` (**Inter**). See `docs/BRAND.md` and `docs/CONVENTION.md` §6.

When the mock and the app diverge, **the Next app + docs win**.
