# Agent entry point

When someone clones this repo and tags **`AGENTS.md`** (or `@AGENTS.md`) with a request to build an app, you are the agent. They usually only say they want to build an app and list the features they want. Follow this flow in order.

**Product / roadmap:** see `docs/PLANS.md` (AAA Portfolio MVP).

**Config & skills:** static data under `config/`; maintenance workflow in `.cursor/skills/aaa-portfolio-config/SKILL.md` and `.claude/skills/aaa-portfolio-config/SKILL.md`; Cursor rules in `.cursor/rules/portfolio-config.mdc`. Overview: `README.md`.
